End-to-End Retail Data Analysis

## Overview

This project is to analyzes the Superstore Retail dataset. The main and focused objective of this analysis on Superstore 
dataset is to transform raw business  data into meaningful insights by perfroming data cleaning, data analysis and visualiztion.
Using Python, SQL, Excel, and Power BI, this project identifies important trends, profit-loss patterns, and areas where 
business performance can be improved, helping support better data-driven decisions.
